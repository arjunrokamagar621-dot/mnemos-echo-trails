🧠 MNEMOS: Echo Trials

“Remember what you cannot see.”

MNEMOS: Echo Trials is an original memory-based puzzle game where players use a temporary ECHO ability to reveal hidden paths, traps, clues, and important locations. When the ECHO disappears, players must rely on memory, logic, and observation to reach the goal.

🎮 Features
🧠 Memory-based puzzle gameplay
🔊 Temporary ECHO vision
🗺️ 10 progressively challenging levels
🎯 False leads and decoy locations
📚 Educational quiz challenges
⭐ Score and performance tracking
📊 Echo Profile
🌌 Atmospheric futuristic UI
🔄 Replayable levels
🕹️ Controls
Key	Action
W A S D	Move
Arrow Keys	Move
SPACE	Activate ECHO
ESC	Pause
🎯 Objective

Use ECHO wisely, remember the environment, solve the challenges, avoid traps and false leads, and find your way to the final objective.

🛠️ Technology
HTML5
CSS3
JavaScript
HTML5 Canvas
Local Storage
🚀 How to Play
Download or clone this repository.
Open the game HTML file in a modern web browser.
Click PLAY.
Use ECHO to reveal the environment.
Remember what you see and solve the puzzle.
